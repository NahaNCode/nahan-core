# v1.6.18

## Managed inbound credential copying

- Adds version 1 of the entry-secret transfer runtime, advertised separately in
  authenticated heartbeats. Older panels can continue operating existing entries.
- Supports copying managed REALITY key pairs, TLS certificate/key pairs and
  Shadowsocks server credentials without changing their cryptographic identity.
- Transfers use the destination's existing local RSA recipient identity and
  AES-256-GCM envelopes. The control plane relays ciphertext, never plaintext
  private keys or passwords.
- Authenticated scope binds source and destination cores, export and import job
  IDs, target draft ID and revision, source reference, secret kind and expiry.
  Deliveries expire within ten minutes and cannot be replayed against another
  core or draft revision.
- Imported material is validated before being committed to the destination's
  private vault. Existing secrets and symlinks cannot be overwritten. Repeated
  delivery of the same material is idempotent; metadata contains public values
  and destination-scoped references only.
- Copying server credentials does not copy customer accounts, grant connection
  group membership or publish an inbound. Those remain explicit panel operations.

## Native updater registration

- Includes the registrar self-process exclusion and the installation repair flow
  developed since v1.6.17. Repairing updater registration does not replace or
  restart the running core.

## Rollout

Deploy the compatible control plane before enabling entry-secret copy. Upgrade
one LAB core first, confirm fresh heartbeat and configuration acknowledgement,
then upgrade production cores sequentially. A core restart interrupts its current
connections; this release does not claim transparent connection migration or HA.

## Verification

Transfer tests cover unchanged source/target identity, private file permissions,
idempotency, tampering, expiry, revision replay, wrong-core requests and symlinks.
The signed-release workflow also runs runtime acceptance and management/accounting
race checks before publishing the immutable signed catalog and binaries.
