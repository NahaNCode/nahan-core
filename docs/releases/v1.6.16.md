# NahaN Core v1.6.16

## Management Reliability

Separates heartbeat and manifest retrieval from serialized engine-management
work. Slow jobs no longer delay these observations. Native traffic delivery
uses a bounded background sender while immutable reports remain on disk until
acknowledged. The embedded Xray version remains 26.10.21.

## All Changes

- Add independent single-flight polling with attempt budgets, backoff and jitter.
- Send immutable heartbeat state without concurrently mutating engine settings.
- Retry transient configuration retrieval without permanently rejecting a revision.
- Preserve terminal authentication revocation and verified IP+TLS fallback.
- Remove additional native Resty retries around the verified transport policy.
- Add bounded per-operation and per-route diagnostics without sensitive payloads.
- Separate traffic persistence from network delivery and cap queue byte usage.
- Persist final counters and stop background reporting cleanly on controller close.
- Fix a controller shutdown race exposed by managed restoration tests.
- Add fault-injection, retained-stream, cancellation and accounting regression tests.

## Upgrade Notes

Deploy backend support for the optional `controlHealth` field before upgrading
cores. Management diagnostics do not replace customer-path probes. Queue limits
retain live counters when persistence fails; they do not guarantee recovery of
unpersisted counters after a crash. Update one canary at a time and validate
configuration acknowledgements, fresh real-path probes and usage delivery.
