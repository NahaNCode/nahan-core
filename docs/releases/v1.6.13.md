# NahaN Core v1.6.13

## Summary

Published-route health checks now run periodically without requiring another
successful configuration poll. Temporary control-plane failures no longer stop
observation of the last committed route.

## Changes

- Keep one bounded periodic health worker per core, independent of control polling.
- Retry failed health delivery on the next observation cycle.
- Resume observation from the validated, committed route journal after restart.
- Preserve observation when a synchronization response omits an unchanged route.
- Bind reports to the exact route revision and digest; discard superseded results.
- Retain explicit cancellation, bounded probe batches and authenticated reporting.
- Add regressions for independent repetition, delivery recovery and revision changes.

## Upgrade Notes

Use the verified updater and signed release catalog. Update cores sequentially:
installation restarts the selected core and can interrupt its connections.
Verify repeated fresh path reports, not just a fresh heartbeat, after upgrading.
This release does not change customer authorization, quotas or forwarding policy.
